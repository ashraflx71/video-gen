# 🎥 Video Gen - محرر ومولد الفيديوهات

تطبيق ويب تفاعلي واحترافي لتحرير وإنشاء الفيديوهات مباشرة عبر المتصفح باستخدام تقنيات JavaScript و Canvas.

## 🌟 الميزات الرئيسية
- 🎨 **محرر اللوحة (Canvas Editor):** إنشاء وتعديل مقاطع الفيديو بصرياً.
- ⚡ **أداء سريع وعالي:** دعم معالجة الوسائط المتعددة متوافق مع خوادم الويب.
- 📱 **متوافق مع الهواتف والكمبيوتر:** واجهة متجاوبة ومناسبة لجميع الأجهزة.
- 🚀 **نشر فوري:** مدمجة ومنشورة تلقائياً عبر GitHub Pages.

## 🛠️ الملفات الأساسية للمشروع
- `index.html`: الواجهة الرئيسية للتطبيق.
- `app.js` & `script.js`: البرمجيات الخاصة بتشغيل التطبيق والتحكم بالفيديو.
- `canvas-editor.js`: محرر الرسوميات والوسائط المرئية.
- `style.css`: التنسيقات والمظهر العام.

## 🚀 كيفية التشغيل
يمكنك استخدام التطبيق مباشرة عبر رابط **GitHub Pages** الخاص بالمشروع، أو فتح ملف `index.html` في أي متصفح.
